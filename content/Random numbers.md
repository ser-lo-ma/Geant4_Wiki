Geant4 is a toolkit for Monte Carlo simulations, these simulations use a (pseudo-) random number generator to mimic real life processes. In Geant4, these random numbers are generated by the engine HEPRandomEngine from the CLHEP library, which takes an integer seed and uses it to generate a sequence of random numbers. 

In Geant4, we are allowed to control multiple things about the engine, such as the seed or the status. We can potentially select different engines, although this is quite complicated. 

#### Seed:
The seed is used to initialize the engine, we can use a set seed, or let the program generate it on its own. This is useful if we aim to create a program that is reproducible (for example if we run the same experiment with some processes disabled), or if we want to ensure that a certain number of experiments are completely independent between them.

#### Status:
We can also save the engine status, this is particularly useful if we want to investigate a crash, as we can run the experiment again from the last known point. Saving the engine status consumes lots of resources and it's not recommended.
